# ``HitchAnalysis``

Turn recordings into figures, and compare them before and after a change.

## Overview

This is what the `hitch` command line tool is built from. Link it into your own tooling to read
recordings, for example to post a comparison on a pull request. Apps do not need it.

## Topics

### Figures of one recording

- ``Summary``
- ``FrameStatistics``
- ``SampleStatistics``
- ``Statistics``

### Comparing recordings

- ``Comparison``
- ``Comparability``
- ``Goals``
