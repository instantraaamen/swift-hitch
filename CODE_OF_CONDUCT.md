# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep the discussion about the work. Harassment
and personal attacks are not acceptable anywhere in the project's spaces.

## Reporting

Report a problem privately through the repository's
[security advisory form](../../security/advisories/new), which only the maintainers can read.
Reports are looked at promptly and handled in confidence.
